# course/ — רשיון אופנוע ים, המוצר בתשלום (שלב 3)

בית הפרויקט לשלב 3: הפיכת ה-demo (`skipper-app.html`) לקורס מלא עם שרת, הזדהות וגביית כסף.
מבוסס על [LAUNCH_PLAN.md](../LAUNCH_PLAN.md). כאן יושבת העבודה בפועל.

## מבנה
- `app/` — הפרונט של הקורס בתשלום (ה-app, נגזר מ-`skipper-app.html`, מושך תוכן מהשרת).
- `api/` — שרת ה-backend: הזדהות, webhook סליקה, הגשת שאלות מוגנות, שמירת התקדמות.
- `docs/` — החלטות, ארכיטקטורה, זרימות (רכישה, auth, קופונים).
- `legal/` — תנאי שימוש, מדיניות פרטיות, מדיניות ביטולים, דיסקליימר.

## החלטות נעולות (2026-08-16)
1. **פלטפורמה:** PWA/web. בלי חנויות אפליקציות בהשקה.
2. **סליקה:** Tranzila. לאלכס יש טרמינל וכל הנדרש.
3. **הזדהות:** מייל + קוד גישה (צמוד מייל, הגבלת מכשירים).
4. **עוסק/חשבוניות:** מוכן, אלכס יכול להוציא חשבוניות.
5. **קופונים:** בתוך ה-scope כבר עכשיו (קוד בשרת + attribution לכל שותף).
6. **Backend:** שרת API חדש ונקי ב-`course/api/`. `publisher/` נשאר לרינדור בלבד.
7. **DB:** Postgres על Railway (התקדמות/XP/SRS פר-משתמש).
8. **הגנת תוכן להשקה:** תוכן מוגש רק מהשרת לקוד תקף + signed URLs ל-Cloudinary. ווטרמארק והגבלת מכשירים = שלב שני.

## סטטוס בנייה
- **פאזה A (תשתית שרת): גמור ונבדק מקצה לקצה מול Postgres אמיתי ב-Railway.** נבדק בהצלחה: רכישה (notify) מנפיקה קוד → קוד פותח 13 שיעורים → התקדמות נשמרת ונטענת מ-jsonb → קופון עם attribution → הגבלת מכשירים (3rd חסום) → notify כפול idempotent. ראה [api/README](api/README.md).
- **מחובר:** `DATABASE_URL` ב-`course/api/.env` (מקומי, gitignored) מצביע ל-Postgres הפומבי ב-Railway. הסכמה נבנית ב-boot.
- **פאזה B (חיבור פרונט): גמור ונבדק בדפדפן.** `app/index.html` מושך תוכן/שם/מחיר מהשרת (הטמעה של 111KB הוסרה). נבדק חי: `/api/free` טוען 10 שאלות ראווה, קוד גישה פותח 13 שיעורים, התקדמות מסתנכרנת ל-Postgres (up+down), הגבלת מכשיר-אחד עובדת, והגישה שורדת reload. ראה [app/README](app/README.md).
- **פאזה C (Tranzila מקצה לקצה): גמור ונבדק בסימולציה.** כפתור רכישה → `/api/checkout` (תמחור קופון בשרת) → דף תשלום → notify → קוד + מייל + חשבונית → חזרה לאפליקציה → poll → פתיחה אוטומטית. נבדק חי בדפדפן מקצה לקצה. קופון 20% נותן ₪79, קופון 100% נותן קוד חינם מיידי. החיבור האמיתי ל-Tranzila = הגדרת `TRANZILA_TERMINAL` (+notify secret), בלי שינוי זרימה. מייל/חשבונית = seams (`email.js`/`invoice.js`), סימולציה עד מילוי env.
- **פאזה D (משפטי+השקה): רובה בנוי.** ✅ PWA (manifest+service worker+icon, נבדק). ✅ תוכן פרטי מ-Postgres (`DATA_SOURCE=db`, importer `admin.js bank import`, נבדק). ✅ טיוטות משפטיות ב-[legal/](legal/) + נוהל אחריות + footer באפליקציה. ✅ [DEPLOY.md](DEPLOY.md) checklist מלא.
  - **נותר לאלכס (דורש חשבונות/החלטות, לא קוד):** למלא ולאשר משפטית את `legal/`, להפוך repo לפרטי (stage-0), לפרוס ל-Railway, ולהחליף env לאמיתי (Tranzila/מייל/חשבונית). signed URLs ל-Cloudinary = seam אופציונלי.
