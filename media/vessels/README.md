# ספריית כלי שייט (top-view vessel icons)

אייקוני כלי שייט **ממבט-על** (bird's-eye), חרטום **למעלה**, רקע **שקוף** (PNG), בסגנון
אחיד (איור שטוח, קו נכחול כהה). משמשים את שושנת הרוחות ב-l12: כל כלי מעורב מצויר במקום
המשולש, מסובב כך שהחרטום פונה למרכז השושנה. נוצרו פעם אחת (nano_banana, מבט-על) + הסרת
רקע (`remove_background`), והוקטנו ל-400px רוחב. אל תיצור מחדש — שמור אחידות.

| קובץ | טיפוס | סימן יום מתאים |
|---|---|---|
| `speedboat.png` | סירה מהירה / מנוע (ברירת מחדל ל"אתה") | אין |
| `workboat.png` | ספינת עבודה / גורר (מוגבל בתמרון RAM) | כדור-מעוין-כדור (79/87/89/90) |
| `nuc_damaged.png` | ללא שליטה (NUC) / על שרטון | שני כדורים (80/81) |
| `fishing_net.png` | ספינת דייג עם רשת | שני חרוטים (84) |
| `sailing_sail.png` | מפרשית עם מפרש | אין |
| `sailing_bare.png` | מפרשית תחת מנוע / תורן חשוף | חרוט קודקוד-למטה (20/82) |

## איך זה עובד (scenes.js)
`generateCompassRoseScene(qText, useBoats)` — הקורא של l12 מעביר `useBoats=true` (l11 נשאר
משולשים). מיפוי סימן→סוג-כלי ב-`CR_SIGN_TO_TYPE`; סימן שאין לו טיפוס = מנוע (speedboat).
הכלי מסומן דרך `crBoat`, האות דרך `crVesselLabel`, והסימן (יום/דגל/אות-קולי) בכרטיס מעל
האות דרך `crSignCardAbove`. בסיס ה-URL: `media/vessels` דרך raw.githubusercontent
(עוקף ע"י ה-global `VESSEL_IMG_BASE` לרינדור מקומי לפני push).
