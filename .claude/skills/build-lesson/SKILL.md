# build-lesson — צינור מערך שיעור מקצה לקצה

כל מה שכבר נקבע נמצא כאן ובכלים ה-committed תחת `tools/lesson/`. **אל תרכיב שום שלב ב-scratch מחדש ואל תשאל את אלכס איך למתג/לנקד/להרכיב — זה סגור.** ה-scratch נמחק בין סשנים; הכלים הם המקור המתמשך.

## מפת הצינור

| שלב | כלי (committed) | קלט → פלט |
|---|---|---|
| 1. קריינות | `tools/lesson/tts.py` | קובץ VO (`## sid`) → `seg_<sid>.mp3` |
| 2. כרטיסים | **ייחודי לשיעור** (ראה למטה) | נתוני השיעור → `<sid>.png` |
| 3. הרכבה | `tools/lesson/assemble.py` | כרטיסים + קריינות → `lesson.mp4` גולמי |
| 4. מיתוג | `tools/lesson/brand.py` | `lesson.mp4` → `<נושא>.mp4` ממותג |
| 5. ארכוב | ידני | הכל לתוך `lessons/l11/cards/<נושא>/` |

הניקוד (`tools/lesson/niqqud.py`) מוחל אוטומטית בשלב 1; המילון הקנוני הוא `references/niqqud-lexicon.md`.

## שני קבצי הטקסט — אל תבלבל

- **קובץ VO לבנייה** (קלט לצינור): כותרות סעיף `## <sid>` עם מזהה **מילה אחת** (`s1`, `s02_intro`). כל סעיף = כרטיס אחד. זה מה ש-`tts.py` ו-`assemble.py` קוראים.
- **הקובץ המלווה** (`<נושא>.txt`, תוצר מסירה): פרוזה מנוקדת עם כותרות עברית קריאות. **מנוקד** (`python tools/lesson/niqqud.py < in > out`). נמסר תמיד לצד ה-mp4 — בלעדיו המסירה לא שלמה.

## שלב 1 — קריינות

```bash
python tools/lesson/tts.py <vo.txt> <aud_dir>
```
קול `he-IL-HilaNeural`, rate `-10%`. מחיל מילון ניקוד, ומגן מפני קיטוע של edge-tts (מודד CPS, מפיק מחדש עד 3×, **עוצר** אם קצר). אם עצר על סעיף — תקן טקסט/פצל, אל תתעלם.

## שלב 2 — כרטיסים (ייחודי לכל שיעור)

זה החלק היחיד שאינו פקודה אחת: לכל שיעור ויזואל משלו. הכללים הקבועים:
- קנבס **1280×720**, פונט Arial/Assistant, עברית דרך `bidi.get_display` (RTL).
- פלטה: רקע נייבי `#0E1A2D`, בר עליון ירוק `#22A05A`, פאנל `#182842`, טקסט `#F0F5FA`, אקסנט כתום `#DCA03C` / אלמוגי `#E0817C`, כחול `#5A96DC`.
- שם קובץ כרטיס = **המזהה** מקובץ ה-VO: `<sid>.png` (למשל `s01_intro.png`).
- רפרנס עיצוב מחייב: כרטיסי מערך קיים, למשל `lessons/l11/cards/אופנוע ים - כללי/` (s01–s21).
- לשאלות עם **תמונת מפה אמיתית** — ראה `src/maps/` (Leaflet+puppeteer). אל תוסיף SVG סינתטי מעל מפה.

כתוב את סקריפט הכרטיסים לקובץ `.py` בסקרצ'פאד (לא heredoc — Windows), הרץ, וודא שכל `<sid>.png` קיים לפני שלב 3.

## שלב 3 — הרכבה גולמית

```bash
python tools/lesson/assemble.py --vo <vo.txt> --audio <aud_dir> --cards <cards_dir> --out <lesson_raw.mp4>
```
גוזם שקט, מרפד זנב 0.5ש׳, קליפ סטילס לכל כרטיס באורך הקריינות, משרשר לפי סדר ה-VO. נופל אם חסר `seg_<sid>.mp3` או `<sid>.png`.

## שלב 4 — מיתוג (קבוע, לא לשחזר)

```bash
python tools/lesson/brand.py <lesson_raw.mp4> "lessons/l11/cards/<נושא>/<נושא>.mp4"
```
כרטיס לוגו פתיח (3ש׳) וסיום (4ש׳, "תודה שצפיתם") מ-`media/my_logo.jpg` + סימן מים בפינה השמאלית-עליונה לכל האורך. **הסרטון לא מתחיל בסרטון מונפש** — אל תשתמש ב-`media/intro-meshit11.mp4`.

## שלב 5 — ארכוב (חוק קבוע)

`lessons/l11/cards/<נושא בעברית>/` (שם הנושא, **לא** `uX`), ובתוכו יחד: `<נושא>.mp4`, כל כרטיסי ה-PNG, ו-`<נושא>.txt` המנוקד. הארכוב הוא המקור המתמשך; ה-scratch מסתובב.

## כללי VO שחייבים להתקיים בטקסט (לפני שלב 1)

- **הקראת אות התשובה:** כל תשובה נפתחת "התשובה הנכונה היא ב: <טקסט>". **בלי גרש** אחרי האות — edge-tts משמיט את האות אם יש גרש.
- **אותיות דגל/לטיניות** (`A`, `B`, `N`, `C`, `S O S`) — לטיניות עם רווחים כדי שייקראו כאותיות.
- **מספרים** — במילים, לא ספרות.
- הרץ `no-ai-slop` על נוסח פונה-משתמש (כרטיסים, VO, קומפניון) לפני סיום. בלי em dashes.
- אמת תוכן ותשובות מול מפתח התשובות הרשמי **לפני** רינדור.

## הרחבת המילון

מילה חדשה שאלכס מנקד → `python tools/add-niqqud.py "בַּיַּבָּשָׁה"` (מוסיף ל-`references/niqqud-lexicon.md`). מאותו רגע `niqqud.py` מחיל אותה אוטומטית. אל תבקש לנקד מילה שכבר במילון.
