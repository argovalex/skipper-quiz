# מילון ניקוד לקריינות עברית — Higgsfield / Remy

מילון תיקוני הגייה לטקסט עברי שנשלח למנוע TTS (text2speech_v2, variant=elevenlabs, voice Remy).
המנוע קורא עברית לא־מנוקדת ולעיתים טועה. הטבלה למטה מכילה **רק** מילים שנבדקו והצורה שעובדת.

## כללי־על
- לנקד **רק** את המילים ברשימה. לא לנקד את כל הטקסט — ניקוד מלא פוגע בזרימה.
- מספרים: לכתוב במילים ("שבעים מטר", לא "70 מ'").
- מונחים לועזיים / ראשי תיבות: כתיב פונטי בעברית ("צ'רט פלוטר", "ג'י פי אס", "וי אייץ' אף").
- פיסוק = השהיות: פסיק → הפסקה קצרה; נקודה → הפסקה ארוכה.
- **אות אנגלית כתובה בעברית (אֵס, אֵן, סִי, אוֹ...) — הפרד ברווח בלבד, לעולם לא בפסיק.** פסיק מיד אחרי אות כזו **מעוות את הקול** (נבדק ב-edge-tts/Hila). לכתוב "אֵס אוֹ אֵס", לא "אֵס, אוֹ, אֵס". ⚠️ `applyVoFixes` ב-`tools/quiz-app/vo.js` דווקא מכניס פסיקים — לקריינות שיעורים אל תריץ רצפי-אותיות דרכו; כתוב אותם ידנית מנוקדים עם רווחים.
