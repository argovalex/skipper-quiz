## מקרים מיוחדים
- **איאלה (IALA):** `אִיאָלָה`. אחריה מופיעה **אות אזור המיצוף** — `A` (ישראל) או `B`. כתוב את האות לטינית עם רווחים כדי ש-edge-tts יקריא אותה כאות: `שִׁיטַת אִיאָלָה A`.
- **מיידיי (Mayday):** `מֵיִדֵיי`.
- **פירוטכניים:** `פִּרוּטְכ-נִים` — המקף מפצל את ההברה ומתקן הגייה.
- **אותיות דגל / אותיות לטיניות ב-VO של שיעור:** כתוב אותן **לטיניות עם רווחים** כדי ש-edge-tts יקרא כאות: `S O S`, `N`, `C`. (בטקסט פונה-משתמש/כרטיסים אפשר `אן מעל סי`.)
- **מספרי שאלה:** מילים עבריות, לא ספרות (`heNum` בצינור הבנק; ידני במערכי שיעור).
- **מד"א (מגן דוד אדום):** כתוב `מָאדָא` (מילה אחת, בלי גרשיים) כדי ש-edge-tts יהגה "מָאדָא". הופיע במערך עזרה ראשונה (נוהל החייאה).
- **הקשר עזרה ראשונה:** `מַנְשִׁים` (לפני שאתה מנשים), `בֵּית הֶחָזֶה` (עיסויי בית החזה), `מוּנָע` (אופנוע ים מונע בסילון), `מִכְנָסַיִים` (מכנסיים נגד החלקה), `מֵדוּזָה`/`זַהֲרוֹן` (ארס ימי).

## הרחבה
כשאלכס מחזיר ניקוד חדש — הוסף אותו כאן מיד, ומאותו רגע השתמש בו בלי לשאול שוב.

הוספה ישירה (אלכס מריץ בעצמו):
```bash
python tools/add-niqqud.py "בַּיַּבָּשָׁה"
```
מקבל מילה מנוקדת (או כמה מופרדות ברווח), גוזר את הצורה הרגילה ע"י הסרת ניקוד, מוסיף שורה לטבלת המילים, ומדלג/מעדכן אם כבר קיים. לצורה רגילה מותאמת ידנית: `--plain "מיידיי"`.
