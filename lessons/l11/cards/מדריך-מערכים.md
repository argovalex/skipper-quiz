# מדריך מערכי שיעור — רשיון אופנוע ים (L11)

מסמך אחד שעובר סינריו-סינריו. המטרה: כל מה שכבר נקבע רשום כאן, אין צורך לבקש מחדש.
המקור הקנוני לתוכן כל מערך הוא קובץ ה-`.txt` המלווה בתיקיית המערך (`cards/<נושא>/<נושא>.txt`).

### קובץ מלווה
- לכל סרטון קובץ `.txt` באותו שם, **מנוקד**, לצד ה-mp4. בלי הקובץ המלווה — המסירה לא שלמה.

### מבנה מערך (תבנית קבועה)
`פתיח` ← `סעיפי תוכן` ← `שאלה לדוגמה` + `תשובה` (עם אות) ← `סיכום` / `מה לזכור`.
מערכים עם הרבה תמונות (אותות קוליים, סימני יום) מסתיימים ב**מונטאז׳ סיכום לפי מספר תמונה**.

### ארכוב
- כל מערך = תיקייה אחת `cards/<נושא בעברית>/` המכילה: `<נושא>.mp4`, כל כרטיסי ה-PNG, `<נושא>.txt`.
- שם התיקייה = הנושא, **לא** `uX`. הארכוב הזה הוא המקור המתמשך (ה-scratch מסתובב).

## חלק ג׳ — מערך אחר מערך

### אופנוע ים - כללי
כללי-על של הכלי למבחן התאוריה.
**עובדות מפתח:** רק משיט מוסמך נוהג (חריג: תלמיד שעבר עיוני בשיעור מעשי בפיקוח). מקסימום **3 אנשים**. איסור אלכוהול על **הנהג והנוסע**. מדומם חירום מחובר **לנוהג** (לא להגה/נוסע). ציוד חובה: חגורות הצלה, מצוף עשן אחד, מדומם מנוע, מראת איתות. **4 תעודות** בהפלגה (משיט, כלי שיט, מזהה, ביטוח). ביקורת כושר שייט **אחת לשנתיים**. מספר זיהוי **≥10 ס"מ**. חגורות הצלה = מספר המורשים. אין הפלגה בחשיכה/ראות לקויה. עומק מינימלי להפעלת מנוע **60 ס"מ**. עשן שחור מכלי סמוך = תקלה, מסמן לנטוש. ספינת אם לצולל רק עם דגל **98** ומשיט מוסמך.
**שאלות לדוגמה:** מדומם חירום → **ג** (מחובר לנוהג). מקסימום אנשים → **ג** (לא יותר משלושה).

### אזורי שיט ומהירויות (יחידה 2)
**שלושת המספרים:** 300 מ׳, 5 קשרים, מייל אחד.
**עובדות מפתח:** 0–300 מ׳ מהחוף: עד **5 קשרים** + **בניצב לחוף (90°)**, שתי המגבלות יחד. 300 מ׳ עד **מייל אחד** מקו שפל המים = אזור פתוח (בכנרת אין מגבלת מייל). חוף רחצה מוכרז = **אסור מוחלט**; מתקרבים עד **50 מ׳ מהצדדים** ו-300 מ׳ מקו שפל. אזור סגור מזוהה לפי **הכרזה רשמית**, לא מרחק. שטחי אש: **30** מול עתלית, **24** מול ראשל"צ, **82** מול פלמחים. נחלים אסורים לחלוטין (שפך הירקון). מפרץ אילת חוף צפוני: אסור עד **1000 מ׳**.
**שאלות לדוגמה:** מהירות+כיוון ב-200 מ׳ → **ב**. טווח מרחק מותר → **ג**. התקרבות לחוף רחצה → **ג**. 2 מייל מ׳ מערבית לעתלית → **ב** (אסור). כניסה לשפך הירקון → **ג** (אסור).

### דגל צולל (יחידה 4)
**עובדות מפתח:** דגל **אלפא (A)**, תמונה **98**, לבן/כחול מפוצל = צוללנים במים, שמור **200 מ׳**. ספינת אם לצולל: אופנוע ים מותר רק עם דגל אלפא + משיט מוסמך קבוע. דגל **בראבו (B)** אדום מפוצל = חומרים מסוכנים. דגל **אוסקר (O)** אדום/צהוב = אדם בים. **N / C / H** כדגל בודד = לא משנים דבר לזכות מעבר. כלל: כל דגל עם שסע = דגל אזהרה.
**שאלה לדוגמה:** מרחק מדגל צוללנים → **200 מ׳**.

### מצוקה (יחידה 5)
**כלל זהב:** זיהית מצוקה → חובה לגשת ולעזור. חריג יחיד: אם הסיוע מסכן אותך/הצוות (צריך להוכיח).
**סימנים:** שמיעה (4): מיידיי ×3, צפירה ממושכת, קול נפץ, SOS. פירוטכניים (3): מצוף עשן, רקטה, לפיד יד. יתר (5): נפנוף ידיים, ראי איתות, אש, דגל מרובע+כדור שחור, **N מעל C**.
**5 שחוזרים במבחן:** דגל מרובע+כדור שחור · N מעל C · עשן כתום סמיך · צפירה ממושכת רצופה · SOS.
**2 מלכודות:** "7 צפירות ארוכות" לא קיים (זו צפירה אחת ממושכת). דגל בודד ≠ מצוקה (רק N מעל C).
**שאלות לדוגמה:** עשן כתום → מצוקה, ניגשים. אות יעיל לאופנוע ים → SOS בראי איתות/מתכת מבריקה.

### זכות מעבר (יחידה 6)
**3 שלבים:** (1) סכנת התנגשות = כיוון יחסי כמעט קבוע (בתחום 5°) **וגם** טווח קטֵן. (2) חוק המשפחות לפי כושר תמרון: ממוכן מפנה למפרשית → מפרשית לדייג → דייג למוגבל בכושרו → כולם לכלי ללא שליטה. אופנוע ים = ממוכן, מפנה לכולם. (3) שני ממוכנים: חרטום מול חרטום = שניהם ימינה; הצטלבות = **הרואה מימין מפנה**.
**כלל-על:** כלי עוקף תמיד מפנה. מלכודת: דגל בודד לא משנה כלום.
**שאלה לדוגמה:** מול ספינת דיג בסכנת התנגשות → אופנוע הים (ממוכן) מפנה לה.

### סימני יום (יחידה 6b)
**צורות שחורות על התורן:** כדור אחד = **עוגן**. שני כדורים = **ללא שליטה** (ראש היררכיית הפינוי). שלושה כדורים אנכית = **על שרטון**. שלושה במשולש = **שולת מוקשים**. כדור-יהלום-כדור = **מוגבל בכושרו לתמרן**. חבית (צילינדר) = **מוגבל בשוקע**. שני משולשים שעון-חול = **דיג (מכמורת)**. יהלום על גורר + נגרר = **גרירה מעל 200 מ׳** (נחשב ממוכן). משולש קודקוד למטה = **מפרשית תחת מנוע** (נחשבת ממוכן). ליד עבודות תת-מימיות: עובר **בצד היהלום**, לא בצד הכדורים.
**שאלה לדוגמה:** שני כדורים שחורים → ללא שליטה, אופנוע הים מפנה ומתרחק.
**סיום:** מונטאז׳ לפי מספר תמונה (77 עוגן ... 90 מוגבל).

### אותות קוליים (יחידה 8)
**בסיס:** קצרה ≈ שנייה (נקודה), ארוכה ≈ 5 שניות (קו). קוראים משמאל לימין.
**ראות טובה (תמרון):** קצרה אחת = ימינה. שתיים = שמאלה. שלוש = מנוע לאחור. חמש קצרות = ספק/סכנה.
**עקיפה בתעלה צרה:** 2 ארוכות + 1 קצרה = עקיפה מימין. 2 ארוכות + 2 קצרות = עקיפה משמאל.
**מצוקה:** ארוכה אחת מתמשכת = מצוקה. 3 קצרות/3 ארוכות/3 קצרות = SOS. (חמש קצרות = ספק, לא מצוקה.)
**ראות מוגבלת:** לילה **אינו** ראות מוגבלת. צופרים כל **2 דקות**; ממוכן בתנועה = ארוכה אחת כל 2 דקות. אסור לערבב אותות ראות טובה עם אותות ערפל.
**שאלה לדוגמה:** בערפל 3 קצרות (אות ראות טובה) → **ב** (הכלל נכון אך אסור להשמיע בערפל).

### מטאורולוגיה (יחידה 12)
**18 שאלות, כמעט כולן על כיוון הרוח. חמישה כללים:**
1. **אילת** — הסכנה תמיד בחוף הצפוני. דרומית = סוער מאוד בצפון. צפונית = שקט. מזרחית = סוחפת לבסיס חיל הים.
2. **בריזה בקיץ (ים תיכון)** — בוקר: דרום-מזרחית מהיבשה. צהריים: מערבית מהים.
3. **חורף (מערכות לחץ)** — שקע נגד כיוון השעון, רמה עם כיוון השעון. שקע מצפון = מערבית סוערת. רמה מצפון = מזרחית ושקט. רמה מדרום = מערבית. (אל תשנן "רמה=מזרחית" בעיוורון.)
4. **היסחפות לעומק** — מסוכנת הרוח שמנשבת מהיבשה אל הים. ים תיכון = מזרחית. כנרת מזרחית: מזרחית. כנרת מערבית: מערבית.
5. **ים סוער / גרירה** — מזרחית מטעה (חוף נראה שקט אך סוחף). מערבית = סוער בחוף. **גוררים תמיד עם הרוח**, אל היעד שהרוח דוחפת אליו.
**שאלות לדוגמה:** דרומית באילת → **ג** (סוער בצפון). בריזה בצהריים → **א** (מערבית). שקע מצפון → **ג** (מערבית ערה עד חזקה). היסחפות בים תיכון → **ג** (מזרחית). מערביות ערות → **ג** (לא כדאי להגיע). גרירה מהרצליה דרומה ברוח צפונית → **ג** (מעגן תל אביב).

### ניווט וכניסה לנמל (יחידה 13)
**עובדות מפתח:** טווח ראות תלוי בגובה. רוכב ≈ מטר מעל המים → אופק בכ-**2 מייל ימי**. מייל ימי = **1852 מ׳** (≈2 ק"מ). מיצוף **איאלה**: ביציאה מהנמל — אדום מימין, ירוק משמאל. בכניסה — הפוך (אדום משמאל, ירוק מימין).
**שאלות לדוגמה:** טווח ראות מגובה מטר → **ב** (כ-2 מייל). מצופים ביציאה → **א** (ימין אדום, שמאל ירוק).

### סכנות רכיבה ותמרון
**עיקרון-על:** הכל נגזר מאיך הגוף מגיב לתאוצה, בלימה וגלים. **מקור הסכנה הייחודי: סילון מים בלחץ, לא מדחף** (אין מדחף חשוף, כל שאלה על מדחף = מלכודת).
**עובדות מפתח:** האצה זורקת את הנוסע מאחור **אחורה** אל קו הסילון (פגיעות חדירה, מכאן חובת מכנס מגן); בלימה זורקת **קדימה**. נפילה מגל גבוה: לנוהג אחיזה (הגה), **הנוסע מאחור חשוף יותר**. גלי חוף במהירות = נפילה ואיבוד שליטה. מדומם ניתלש = הנוהג נחבט בהגה. גלים גבוהים מהצד = **התהפכות**. גישה לכלי אחר: **לאט, נגד הרוח, דימום מנוע בקרבתו**. ליד כלים: לאט כדי למנוע גלים.
**מקור האיור:** סצנות `scenes.js` מרונדרות ל-PNG (puppeteer) ומוטמעות כפאנל שמאלי. אל תצייר אופנוע ים/דמויות מחדש — משתמשים ב-`sideJetSki`/`sideRider` הקיימים. סצנות מוכנות: `pwc_rider_risk` (האצה), `rider_clothing` (סילון+מכנס), `pwc_helm_impact` (מדומם), `pwc_wave_launch` (גלי חוף), `pwc_beam_capsize` (מהצד+שאלה), `pwc_slow_approach` (גישה). שלוש סצנות **מורכבות** מהרכיבים לפתיח/בלימה/נפילה-מגל (`comp_intro`/`comp_brake`/`comp_wave_fall`) כדי שלא יחזרו תמונות זהות.
**שאלות לדוגמה:** גלים מהצד → **ד** (התהפכות). גישה לכלי → **ב** (לאט, נגד הרוח). מהירות ליד כלים → **א** (למנוע גלים).

### תמרוני ספינה
**ארבעה תמרונים במבחן התאוריה.**
**עובדות מפתח:** גרירת סקי/בננה — האופנוע חייב היתר ל**3 רוכבים**, ועליו **לפחות 2** (נוהג + צופה לאחור בקשר עין רצוף עם הנגרר). גרירת אופנוע ים אחר — חבל בנגרר ל**תפס הקדמי**, אצל הגורר מסביב למושב/תפס אחורי, אורך מומלץ **40 מטר**. יישור אחרי התהפכות — הופכים **רק בכיוון היצרן**, מתניעים **מיד** (הפיכה לצד הלא נכון מכניסה מים למנוע); נעזרים במשקל הגוף על הפגוש, מסובבים כך שהאורך מול הרוח. החפה (עלייה מתוכננת לחוף) — ממקמים **בין שני גלים** לשמירת שליטה.
**מקור האיור:** סצנות `scenes.js` מרונדרות ל-PNG (puppeteer). סצנות: `tow_skier` (גרירת סקי), `tow_craft` (גרירת אופנוע + שאלה), `right_capsized` (יישור), `beaching` (החפה); פתיח מורכב `comp_intro_tmr`. אל תצייר מחדש — `sideJetSki`/`sideRider` הקיימים.
**שאלה לדוגמה:** אורך חבל גרירה בין שני אופנועי ים → **ד** (40 מטר).

### עזרה ראשונה
**כלל זהב:** מעריכים לפני שמטפלים — קודם **נשימה ודופק**.
**עובדות מפתח:** מחוסר הכרה → בדוק נשימה ודופק. טביעה → **אסור** לנסות להוציא מים מהריאות; מנקים פה, משכיבים על הגב, מתחילים עיסויים. החייאה: מד"א **101**, איחוד הצלה **1221**; עיסויים בלבד, עומק **~5 ס"מ**, קצב **100–120** לדקה. מכת חום → **מקררים** (המבחן מפיל עם "לחמם"). ארס ימי → **מחממים** ~40–45°C (חלבונים מתפרקים בחום). סכנה ייחודית: סילון מים בלחץ גבוה מהנחיר → חובה מכנסיים נגד החלקה.
**שאלות לדוגמה:** מחוסר הכרה → **ב** (בדיקת נשימה ודופק). דג ארסי → **א** (חימום אזור הפגיעה).
